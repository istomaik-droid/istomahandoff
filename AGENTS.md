# Инструкции агенту

Этот проект работает по протоколу istomahandoff (docs/, agents/).
Главное правило: НЕТ ЯВНОГО РЕШЕНИЯ ВЛАДЕЛЬЦА = НЕТ ПРАВА НА ДЕЙСТВИЕ.
Перед работой прочитай agents/AGENT_CONTRACT.md и выполни обязательный
первый ответ. Действия: skills/preflight, decision, handoff, incident,
verify — по ситуации (whenToUse в каждом SKILL.md).

Это репозиторий самого протокола: docs/10 — журнал решений о протоколе;
решения других проектов ведутся в их собственных журналах
(agents/AGENT_RUNTIMES.md, «Размещение»). К установленному киту этот клон
подключается как проект (`ISTOMAHANDOFF_PROJECT` — этот каталог): чтение и
pre_deploy_check работают; запись решений и checkpoint_create через MCP
закрыты — журнал протокола ведётся через pull request (DEC-0016).

docs/09 и docs/11 здесь — шаблоны кита: они не заполняются и не
дополняются (instance_init копирует их в новые экземпляры). Версия
протокола этого клона — последняя строка docs/42 его ветки; сверка по
docs/34 п.12 — с ней. Обязательная самопроверка — `python
tools/protocol_lint.py` в этом клоне; tool protocol_lint проверяет клон как
экземпляр, и его предупреждения о копии кита к клону не относятся.
