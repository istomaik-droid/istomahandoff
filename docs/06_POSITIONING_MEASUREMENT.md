# 06. Positioning и measurement

## Обязательно

1. Честные обещания.
2. Основной outcome.
3. Harm metrics.
4. Baseline rules.
5. PASS/FAIL/STOP/INCONCLUSIVE.
6. Запрет выдуманных targets.

## Правила

1. Verdict определяется до теста.
2. Недостаток данных = INCONCLUSIVE, не PASS.
3. Security incident = STOPPED.
4. Метрики без provenance не считаются.
