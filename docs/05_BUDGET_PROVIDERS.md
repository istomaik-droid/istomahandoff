# 05. Budget и providers

## Обязательно

Spend envelope фиксирован. Любой платный provider, лицензия, подрядчик,
hosting, консультация, найм — отдельное решение до обязательства.

## Запрещено без owner decision

- Выбор AI provider.
- Выбор database provider.
- Выбор hosting.
- Выбор object storage.
- Выбор observability.
- Выбор scan provider.
- Включение compression gateway/proxy в цепочку агент→LLM
  (provider-класс: видит и переписывает каждый запрос; self-host тоже).
- Любые external commitments.

R5-решения мандатом deputy не покрываются (docs/46).

## Модель по классу задачи

Стоимость хода = ходы × длина контекста; модель выбирается по типу работы:

- Механические задачи (готовый код в брифе, правки по ревью, выпуск по
  шаблону) — стандартная/дешёвая модель.
- Расследования и проектные решения — сильная модель.
- Финальное ревью на самой дорогой модели — один раз на ветку, перед
  выпуском; повторные поверочные ревью — стандартная модель.

Маппинг по умолчанию переопределяется в PROJECT_PROFILE.
