# 48. Индекс документов и чтение по требованию

## Правила

1. docs/INDEX.md — единственное оглавление протокола: одна строка
   на документ (назначение, тир, когда читать).
2. Тиры: must-read (M) — обязательное чтение в начале работы по
   agents/AGENT_CONTRACT; reference (R) — читается только когда задача
   попадает в его scope.
3. Агент не читает документы тира R «про запас» и не читает docs/
   подряд: сначала INDEX, затем точечно документы по его строкам.
4. Ссылка вместо пересказа: в ответах, memo и evidence агент ссылается
   на docs/NN и DEC-ID, а не копирует текст правил.
5. Одно правило — один документ. Дублирование норм между docs/, agents/
   и промптами запрещено; используются ссылки.
6. Новый документ получает запись в INDEX в том же изменении.
   Покрытие проверяет tools/protocol_lint.py.
7. INDEX не заменяет и не расширяет список обязательного чтения
   agents/AGENT_CONTRACT.
