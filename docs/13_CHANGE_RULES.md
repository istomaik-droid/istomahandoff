# 13. Change rules

| Class | Пример | Действие |
| --- | --- | --- |
| C0 | Формулировка без смены смысла | Trace и review |
| C1 | Выбор принятой реализации | ADR/review |
| C2 | Изменение acceptance/control | Owner slice review |
| C3 | Изменение scope/sequence | Новое решение Owner |
| C4 | Данные/authority/security | Professional review + owner decision |
| C5 | Provider/license/contractor | Spend decision |

## Правила

1. Агент не понижает class.
2. Каждое изменение классифицируется.
3. C3+ требует owner decision.
4. C4+ требует professional review.
5. C5 требует spend decision.
