# 02. Foundation boundary

## Определяется

- domain boundaries;
- identity;
- account;
- membership;
- authority;
- audit;
- receipt;
- correction;
- isolation;
- export;
- recovery.

## Правила

1. Проекты, CRM, финансы и UI не подменяют foundation.
2. Foundation PASS не наследуется автоматически.
3. Global и domain authority разделены.
4. Support content-blind; break-glass — отдельно.
